# Companion compatibility fixtures

Synthetic fixtures use the public v4.0.1 serialization contract in QubeTX/qube-network-diagnostics: src/diagnostics/mod.rs, src/speedtest/mod.rs, src/speedtest/engine_v5.rs and src/speedtest/measurement_v5.rs. They contain documentation-range identifiers, never a captured private report. Only 4.0.1 is currently qualified. Unknown versions require a reviewed fixture update; unreleased 4.0.2 work is not a dependency.
